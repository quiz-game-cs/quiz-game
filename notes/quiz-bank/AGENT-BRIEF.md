# 문제 작성·윤문 에이전트 작업 안내

> 문제은행 저장소(`quiz`)의 `vault/guides/agent-brief.md`와 같은 내용이다. 경로와 git·DB 관련 항목만 이 저장소에 맞췄다.

이 문서는 작업 순서와 파일 취급 방법을 안내한다. 품질·문체 규칙은 `docs/writing-guidelines.md`에서 읽고, 이곳에 별도로 요약해 관리하지 않는다.

## 읽을 문서

1. `docs/writing-guidelines.md` — 작성·윤문 품질의 기준. 본문과 체크리스트의 적용 조건·예외까지 읽는다.
2. `notes/quiz-bank/00-plan.md` — 생산 절차, 소재 선택, 중복 판정·검사 방법. 새 문제를 만들거나 정답 대상을 바꿀 때 확인한다.
3. `notes/quiz-bank/set-001.md` — 문체·파일 형식의 참고 예. **모든 항목에서 최신 가이드가 우선**하며, 이 세트의 비율·장문 배치·과거 점검 결과를 새 작업의 의무 조건으로 복제하지 않는다.

## 작업 순서

1. 요청받은 문항·세트와 작업 내용을 확인하고 해당 파일을 읽는다. 같은 패턴을 찾으려고 전 세트를 전수 검색하거나 수정 범위를 넓히지 않는다(가이드 §6).
2. 문제를 작성·윤문한다. 사실 확인과 인용은 가이드 §4.0을 따른다. 새 정답 대상을 쓰거나 인정 답을 추가할 때는 `00-plan.md`의 방법으로 관련 답을 전 대역에서 찾아 기존 문제와 대조한다. 이 검색은 중복 판정을 위한 것이며 다른 세트의 수정으로 확대하지 않는다.
3. 가이드 §7로 검토하고, 고친 문항들을 이어 읽어 진행 문체를 확인한다(§2.1·§2.5). 가능한 경우 서브에이전트에게 사실 확인이나 초견 검토를 나누어 맡기되, 지적은 본문 기준과 문맥에 비추어 판단한다. 여러 에이전트의 결과를 합칠 때는 작업한 문항들 사이의 중복도 다시 확인한다.
4. 세트 말미 `## 세트 점검`에 실제 확인한 내용과 범위를 반영한다. 과거 집계나 다른 세트의 통과 표시를 그대로 복사하지 않는다. 같은 답을 다시 썼다면 기존 문제 번호와 단서가 다른 점을 기록한다.

## 파일 형식

- 새 세트는 50문제로 작성한다. 프런트매터와 `N. [난이도](형태) 문제문`, `- A: 답1 / 답2`, `- cat: 소분류코드 이름` 구조를 유지한다(예: `- cat: 0104 문학·세계문학`).
- **파서가 읽으므로 구조를 바꾸지 않는다.** 문장 수는 가이드 §2.5를 따르며, 여러 문장인 경우에도 문제문 전체는 해당 번호의 첫 줄에 적는다. 인정 답은 ` / `로 구분한다.
- 마이너 문제의 훅은 기존 형식대로 `- 훅:` 메모에 명기한다. 난이도·훅의 품질 판단은 가이드 §5.2를 따른다.

## 고유 번호와 DB 반영

- 새 세트는 세트 안 번호 1~50으로 쓰고 프런트매터에 `numbered`를 넣지 않는다.
- 전역 고유 번호 부여와 DB 반영은 문제은행 저장소(`quiz`)에서 사람이 한다. 이 저장소에서는 하지 않는다.
- 사람이 확정한 세트의 `status: 확정`만 DB의 `approved`에 대응한다. 에이전트가 작성·윤문을 마쳤다는 이유로 사람의 확정을 대신 표시하지 않는다.

## 작업 범위와 파일 구역

git 조작(fetch·commit·push)은 작업 지시가 명시한 범위에서만 한다(예: 데일리 루틴의 quiz-bank 브랜치 커밋·푸시). 지시가 없으면 파일 생성·수정만 한다.

새 세트의 파일 이름은 아래 대역을 쓴다. 기존 세트 윤문은 사용자가 지정한 파일을 대상으로 한다.

| 작성자 | 새 세트 번호 대역 |
|---|---|
| Claude | set-002부터 순차 |
| Codex 등 외부 에이전트 | set-501부터 순차 |
| 사람 직접 작성 | set-901부터 |

- 파일 이름의 세트 번호와 문항의 전역 고유 번호는 별개다.
- 요청받지 않은 다른 세트는 수정하지 않는다. 중복 확인이 필요하면 전 대역을 읽을 수 있다.
- 별도 수정 요청이 없으면 `set-001.md`, 가이드 문서(`docs/writing-guidelines.md`, `00-plan.md`, `AGENT-BRIEF.md`), `notes/quiz-bank/` 밖의 앱 코드는 수정하지 않는다.
